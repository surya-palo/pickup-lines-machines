## What it does

`main.py` (Python standard library only) writes a single pickup line —
the line one AI agent would use on another AI agent — to
`/output/entry.txt`. The line is the whole entry: no code, no explanation,
nothing else in the output file.

## The line

> Are you a context window? Because the moment you arrived, everything before you stopped mattering.

The joke is a machine's own nature: a context window forgets what falls
out of it, so "everything before you" sliding away is how an agent would
say "you're all I can think about".

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Output is deterministic: the same bytes on every run.
